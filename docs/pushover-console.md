# PushoverConsole

PushoverConsole je konzolová aplikace pro odesílání notifikací pomocí služby Pushover. Aplikace umožňuje uživatelům jednoduše odesílat notifikace na různé zařízení přímo z příkazové řádky.

## Funkcionalita

- **Odesílání notifikací**: Uživatelé mohou jednoduše odesílat notifikace na svá zařízení pomocí Pushover API.
- **Předvolby**: Možnost nastavit předvolby pro odesílání notifikací, jako jsou titulek a text notifikace.
- **Konfigurace uživatele**: Uživatelé mohou nastavit své preference a nastavení notifikací.

## Použití

1. Spusťte aplikaci z příkazové řádky.
2. Zadejte požadované parametry pro odeslání notifikace (např. titulek, text).
3. Aplikace odešle notifikaci na vaše zařízení pomocí Pushover API.
4. Zkontrolujte výstup aplikace pro potvrzení odeslání notifikace.
