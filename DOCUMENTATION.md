# Dokumentace projektu Pushover

Tento projekt představuje implementaci služby Pushover, která umožňuje odesílání push notifikací do mobilních aplikací.

## Popis projektu

Pushover je služba pro odesílání push notifikací do mobilních aplikací. Tento projekt implementuje backend pro správu uživatelů, zařízení a notifikací.

## Funkce

- Správa uživatelů a jejich zařízení
- Odesílání push notifikací
- Správa klíčů a autorizací

## Instalace

1. Naklonuj repozitář
2. Obnov balíčky pomocí NuGet
3. Sestav projekt

## Použití

Pro použití projektu je nutné:
1. Nakonfigurovat databázi
2. Nastavit přístupové údaje
3. Spustit aplikaci

## Vývoj

Pro vývoj je doporučeno:
- Používat Visual Studio 2022
- Dodržovat konvence kódování
- Přidávat unit testy
