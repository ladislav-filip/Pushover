# Přispívání do projektu

Vítejte v projektu PushoverAltair! Tento dokument obsahuje pokyny pro přispívání do projektu.

## Jak přispět

1. Forkněte repozitář
2. Vytvořte novou větev (git checkout -b feature/nova-funkce)
3. Udělejte změny
4. Commitněte změny (git commit -am 'Přidání nové funkce')
5. Pushněte větev (git push origin feature/nova-funkce)
6. Otevřete pull request

## Pravidla pro přispívání

- Všechny změny musí být pokryty testy
- Kód musí odpovídat stylu projektu
- Každý commit by měl mít jasný a srozumitelný commit message
- Přidávejte komentáře do kódu tam, kde je to nutné

## Testování

Před odesláním pull requestu se ujistěte, že všechny testy projdou.
