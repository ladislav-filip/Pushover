# Přispívání do projektu

Vítejte v projektu Pushover! Tento dokument obsahuje pokyny pro přispívání do projektu.

## Jak přispět

1. Forkněte repozitář
2. Vytvořte novou větev pro vaše změny
3. Udělejte změny a přidejte testy, pokud je to možné
4. Otestujte změny lokálně
5. Pošlete pull request

## Pravidla pro vývoj

- Používejte český jazyk pro komentáře a dokumentaci
- Dodržujte konvence kódování projektu
- Všechny změny musí být pokryty testy
- Přidávejte komentáře k významným změnám

## Testování

Před odesláním pull requestu se ujistěte, že:

1. Všechny existující testy projdou
2. Přidali jste nové testy pro novou funkcionalitu
3. Změny nezpůsobí regresi

## Odesílání pull requestů

Při odesílání pull requestu:

1. Popište, co váš pull request dělá
2. Ujistěte se, že je všechno správně otestované
3. Požadujte review od ostatních vývojářů

Děkujeme za váš přínos!
